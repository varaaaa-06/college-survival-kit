A ghost student college survival kit
For those students who skip college more than they attend...This is practically your operating system but in a aesthetic sparkly way

A personal dashboard for a student who is enrolled. Technically. 

Built for the Codédex September 2026 Back 2 School Challenge.

 Features
- 📊 Chaos Level slider with live mood verdicts
- ⏰ Deadline countdown with urgency messages
- 🔥 "How Cooked Am I?" random verdicts
- ✅ Labour To-Do (no wages)
- 📚 Study Hours tracker
- 📓 Daily Journal (one entry per day)
- 🎭 Excuse Generator (copy-paste ready)
- 💀 Days Until They Kick Me Out counter
- ✍️ Guestbook with localStorage persistence
- ✨ Y2K aesthetic: floating silver & gold stars, cursor trail, under-construction banner

Tech
HTML · CSS · JavaScript · localStorage · zero dependencies
